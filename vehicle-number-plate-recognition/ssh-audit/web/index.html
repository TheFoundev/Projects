What a server says before you trust it.

SSH Audit connects to a server, reads its banner and its key exchange packet and reports every algorithm that is on the weak list, with a score and a grade for the server as a whole.

Architecture

How it works

The audit speaks the SSH protocol far enough to be useful: the banner is the first line the server sends, and the key exchange packet that follows is read from its length, its padding length and the name lists it holds. The names of the six groups are matched against a list of the algorithms that are known to be weak, every match is a finding, and the score of the server starts at a hundred and loses twenty points for every finding.
