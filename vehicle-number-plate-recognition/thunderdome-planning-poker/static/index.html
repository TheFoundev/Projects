Planning poker that runs itself.

A real-time planning poker, retrospective and stand-up server. The cards are pushed to every browser over server-sent events, so the room sees the same estimate at the same second.

What it does

The capabilities

Every panel below is served by the real API of this project — nothing here is a mock-up.

◆

Planning poker

Every player picks a card in secret; the average, the spread and the outliers are computed when the cards are revealed.

▤

Retrospectives

A column board with the mood, the went well, the to try and the actions, pushed live to the room.

☀

Daily stand-ups

A shared board for yesterday, today and the blockers, with the same live push.

⚿

One facilitator

The token that may reveal the cards is handed out once, so nobody can spoil the round.

⇄

Live over SSE

The state of the room is pushed to every browser; there is no polling and no refresh.

⛁

No dependency

The whole server is the Go standard library: no database, no message broker, no build step.

Architecture

How it works

The server keeps the sessions in memory and pushes every change to the browsers over server-sent events. The facilitator token is given once, to the one who opens the room, and every reveal checks it.

GoServer-sent eventsStandard library only
The API

Endpoints

MethodPathWhat it does
POST/api/sessionsOpen a room and get the facilitator token
POST/api/sessions/{id}/joinJoin a room as a player or as the facilitator
POST/api/sessions/{id}/voteCast a card
POST/api/sessions/{id}/revealReveal the cards (facilitator token)
POST/api/sessions/{id}/notesAdd a note to a retrospective column
GET/api/sessions/{id}/eventsThe stream of changes of the room
