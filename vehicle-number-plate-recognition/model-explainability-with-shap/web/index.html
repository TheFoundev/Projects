The score, broken down into the reasons.

An explainability report for a tabular model: the SHAP values of every prediction break the answer into the contribution of every feature, the mean absolute value of those values ranks the features, and a local explanation shows why one row was scored the way it was.

Architecture

How it works

A random forest is fitted on a tabular dataset with a known non-linear signal and one noise column. The TreeExplainer of SHAP computes the attribution of every feature for every prediction, and the values of a row add up to the difference between the expected value of the model and the prediction. The mean absolute value over the rows ranks the features, and a permutation importance and a partial dependence curve are computed next to it, because they answer a different question.

The API

Endpoints

MethodPathWhat it does
GET/api/summaryThe R2, the MAE, the top feature and its importance
GET/api/importanceThe SHAP importance of every feature, from the biggest to the smallest
POST/api/explainExplain one row of the test set
POST/api/trainFit the model again and answer with the new metrics
GET/console.htmlThe console of this site
