A big table, read in pieces and never held whole.

Strata reads a partitioned set of order files without holding them in memory: every partition is read on its own, the group-by is done per partition and the partial results are merged, so only the small summary is ever kept whole.

Architecture

How it works

The orders are written as partitioned CSV files, one file per partition, with a region, a product, a quantity and a price in every row. The pipeline reads a partition, groups it by region and product, and keeps only that small frame; the partial frames are concatenated and grouped once more, which is the merge of the whole. The result is written as Parquet when the library is there and as CSV otherwise, and the console reads that file back, so the numbers on the page are the numbers that are on the disk.
