The joints of a person, as fast as the frames come.

Posture estimates the seven joints of a person in every frame: the bright pixels of the picture are found, the parts of a person are joined into one box, and a trained ridge regression reads the joints off the brightness of the box.

Architecture

How it works

The estimator has the shape of a top-down pose detector: a detector groups the bright pixels of the frame into the boxes of the people, a keypoint regressor turns the brightness of a small grid of every box into the seven joints, and the PCK is the metric. The regressor is a ridge regression over the frames of the set, fitted in closed form, so the model is a handful of learned numbers instead of a network. The frames come from the simulator, from a picture that is uploaded or from a camera when OpenCV is installed.

The API

Endpoints

MethodPathWhat it does
GET/api/summaryThe metrics of the trained model, the error of every frame and the joints
GET/frameThe joints of the next frame of the simulator, as JSON
POST/frameEstimate the pose of an uploaded picture

POST/trainFit the model again and save it

Quick start

Run it locally

# python main.py train            # the metrics of the regressor
# python app.py                   # the API and this site
# POSE_PORT=8309 python app.py    # the API and this site on port 8309
# pytest -q                       # 15 tests
