The patch that does not look like the fabric.

An anomaly detector for material textures: a PCA is fitted on the clean patches, and a patch whose reconstruction error passes the threshold of the clean set is called a defect. The scores are measured with the ROC AUC, the precision and the recall.

AUC, precision and recall

Three measures of the same detector, so a good AUC cannot hide a bad threshold.

◔

The threshold is learned

It is the ninety-fifth percentile of the error of the clean patches.

⚠

Only image-level labels

Where the defect sits inside the patch is not scored.

Architecture

How it works

The material is a textured patch built from a constant level, a sinusoidal grain and a little noise; a defect is a bright scratch or a dark blotch. The PCA is fitted on the clean patches only, and the reconstruction error of a patch is the mean squared difference between the patch and its reconstruction. The threshold is the ninety-fifth percentile of the error of the clean training patches, and every test patch is compared with it.

The API

Endpoints

MethodPathWhat it does
GET/api/summaryThe AUC, the precision, the recall and the threshold of the detector
GET/api/scoresThe anomaly score of every test patch, with the true label next to it
POST/api/scanScan a fresh patch and answer whether it passes the threshold
POST/api/trainFit the detector again and answer with the new metrics
GET/console.htmlThe console of this site
