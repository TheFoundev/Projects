Posture estimates the seven joints of a person in every frame: the bright pixels of the picture are found, the parts of a person are joined into one box, and a trained ridge regression reads the joints off the brightness of the box.

The server can be locked with the environment variable POSE_API_KEY. The session is a signed cookie; the key is checked on every protected route. Without a key on the server the console is open and the sign-in form of the console uses the account demo.
