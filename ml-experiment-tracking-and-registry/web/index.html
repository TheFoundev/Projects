Architecture

How it works

A logistic regression, a random forest and a gradient boosting model are fitted on the same training split and scored on the same test split. Each of them is pickled into artifacts/models and appended to a SQLite table with its name, its parameters, its accuracy and its F1. The best run is the row with the highest accuracy, and the endpoint that answers it reads the table every time instead of keeping it in memory.

The API

Endpoints

MethodPathWhat it does
GET/api/summaryThe number of runs, the best model and its accuracy and F1
GET/api/runsEvery run of the registry with its parameters and its artefact
GET/api/bestThe best run of the registry
POST/api/trainFit the three models again and answer with the new metrics
GET/runsThe run list of the service, unchanged
GET/console.htmlThe console of this site
