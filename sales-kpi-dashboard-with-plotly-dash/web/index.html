Revenue, orders and the average basket, live.

KPI Deck turns a table of sales orders into the numbers a shop is run on: the revenue, the number of orders, the average order value, the growth of the last thirty days against the thirty days before, and the products and the regions that bring the money in.

Architecture

How it works

The pipeline generates ninety days of synthetic orders, writes them to artifacts/sales.csv and works out the KPIs with pandas: the revenue is the sum of the line, the average order value divides it by the number of orders, and the growth compares the last thirty days with the thirty days before. The same numbers are written to artifacts/kpis.json, and the Flask application of the project serves the dashboard and the JSON API of this site from them, so the console and the dashboard always show the same run.

The API

Endpoints

MethodPathWhat it does
GET/api/summaryThe KPIs of the running instance and the revenue of every product and region
GET/api/kpisThe KPIs as they are written to artifacts/kpis.json
GET/api/productsThe revenue of every product
GET/api/regionsThe revenue of every region
POST/api/rerunRun the pipeline again and answer with the new KPIs
GET/chartThe daily revenue of the last run
GET/demoThe dashboard of the project, unchanged
