The same catalogue, four ways to rank it.

Scorecard runs four recommenders over the same ratings: the popularity, the item-item cosine, a truncated SVD and an NMF, and it gives every one of them the same precision@5, the same recall@5 and the same catalogue coverage.

Architecture

How it works

The ratings are simulated with a popularity effect and a taste per viewer, so the ground truth of the data is known. The four recommenders turn the same matrix into four score matrices: the popularity sums the columns, the item-item recommender multiplies the matrix with the similarity of the items, and the SVD and the NMF reduce the matrix to eight factors and rebuild the scores from them. Every recommender is measured with the same loop, so a difference in the numbers is a difference in the method and not in the measurement.
